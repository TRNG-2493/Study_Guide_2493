# Jira Setup Checklist (Part 5)

Reference: Introduction to Jira lesson, sections 6, 8, 9, 11, 15. Jira menus change from time to time; look for the closest match to the names below.

## A. Account and project

- [ ] Sign up for a free Jira Cloud account and create a site.
- [ ] Create a project: template **Scrum**, team-managed.
- [ ] Name: "Project 1 - QE Foundations". Key: **QEA** (or a variation such as QEAJS if taken). Write the key in your plan.

## B. Epic and stories

- [ ] Create 1 Epic: "User Registration and Login" (add the Product Goal in the description).
- [ ] Create story 1 using `user-story-template.md`.
- [ ] Create story 2.
- [ ] Create story 3.
- [ ] Create story 4.
- [ ] Create story 5 (add more if you like).
- [ ] Every story has: the "As a ... I want ... so that ..." sentence, 2+ Given/When/Then criteria in the description, a story point value, and the epic as its parent.
- [ ] Every story meets your Definition of Ready checklist.

## C. Order and people

- [ ] Order the backlog by dragging: the most valuable and riskiest stories at the top.
- [ ] Write one sentence in your plan on why the order is what it is.
- [ ] Invite a placeholder teammate (Project settings, Access / People) and assign one story to them.
- [ ] List the Scrum roles of both people in your plan.

## D. Sprint 1

- [ ] Create a sprint and drag in stories (do not overload; sum the points and check that it is realistic for a new team).
- [ ] Click Start sprint. Enter a sprint goal (one sentence about the outcome, not ticket numbers), a duration (for example 2 weeks) and a start date.
- [ ] Open the board and move one card from To Do to In Progress.

## E. Evidence

- [ ] `jira-screenshots/01-backlog.png` (ordered backlog)
- [ ] `jira-screenshots/02-epic-and-stories.png` (epic with its stories)
- [ ] `jira-screenshots/03-story-detail.png` (one story with acceptance criteria and points)
- [ ] `jira-screenshots/04-sprint-board.png` (active sprint, goal visible, one card moved)
- [ ] `jira-screenshots/05-burndown-or-sprint-report.png` (burndown or sprint report; an empty chart is acceptable on day one)
- [ ] Export the backlog to CSV and save as `jira-backlog-export.csv`.

## F. Last check

- [ ] Sprint is started, with a goal.
- [ ] The project is kept (Tuesday builds on it).
