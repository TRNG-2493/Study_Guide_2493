# Exploratory Charters and Session Sheet

## Charter format
Explore <target area>
With <resources, tools, data, heuristics>
To discover <information: risks, bugs, questions>

| ID | Explore | With | To discover | Time box |
|---|---|---|---|---|
| EC-01 | | | | 20 min |

Checks: one area, one mission, a time box, no step-by-step script, and "to discover" is information, not "to verify that it works".
