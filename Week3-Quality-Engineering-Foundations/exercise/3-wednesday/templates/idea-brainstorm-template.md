# Test idea brainstorm (Part 1)

## What-if prompts (answer each with at least one idea)

1. What if a field is empty, or only spaces?
2. What if the text is one character shorter or longer than the rule allows?
3. What if the value is exactly on the limit?
4. What if the letters are in a different case?
5. What if a required choice (checkbox) is skipped?
6. What if the same thing is done twice?
7. What if the user repeats a wrong action many times?
8. What if the error message says too much?
9. What if the form fails: is the data still saved?
