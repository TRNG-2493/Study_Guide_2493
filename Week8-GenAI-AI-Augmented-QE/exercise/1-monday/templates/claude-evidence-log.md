## The five review questions (apply to every reply)

```text
1. CORRECT?   Does it match the requirement / the docs / the log?
2. INVENTED?  Did it add a rule, method, flag, feature or fact nobody gave it?
3. MISSING?   Boundaries, negative cases, the actual error line?
4. CHECKABLE? How would I prove it right or wrong in 5 minutes?
5. SAFE?      Did anything sensitive go in? Could this output mislead someone?
```
