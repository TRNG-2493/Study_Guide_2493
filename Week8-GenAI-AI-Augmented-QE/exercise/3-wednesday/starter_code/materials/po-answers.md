# Product owner answers for US-420 (use ONLY if your instructor is not playing the PO)

Open this file **after** you have committed your question log. Answer each question in your log
with the closest entry below. If none of the entries answers your question, the answer is
**"Not decided yet"** and the question stays OPEN.

| Topic | PO answer |
|---|---|
| Upper / lower case in the code | Codes are not case-sensitive: lower-case letters are accepted and treated as upper case. |
| Spaces or dashes inside the code (for example `QATEST26-ABCD-1234`) | Not decided yet. Do not test it this sprint. |
| What "order total" means | The final amount the shopper pays, including shipping and tax. |
| Gift card balance larger than the total | The gift card pays the whole total; the remainder is 0.00 and no card payment is requested. The unused balance stays on the gift card. |
| Expired gift cards | Expiry is not part of US-420. Do not test it. |
| More than one gift card per order | Not part of US-420. Do not test it. |
| "Applied quickly" (AC5) | Out of scope this sprint. The platform team will set a performance target later. |
